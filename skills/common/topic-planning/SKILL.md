# 目的

使用此技能将宽泛内容想法转化为有边界的选题计划，让后续阶段无需猜测即可使用。

# 何时使用

在大纲、脚本、分镜规划、生产打包或平台适配之前使用。

# 输入

- 初始想法或任务。
- 目标受众。
- 目标平台或频道类型。
- 期望形式、长度、语气和约束。
- 已知排除项或敏感边界。

# 上下文路由

加载项目简报，以及避免重复既有决策所需的本地规划记录。除非任务要求，否则不要加载生产、发布或记忆层。

# 工作流

1. 用一句清晰的话重述核心主题。
2. 定义受众，以及他们应理解或采取的行动。
3. 选择平台和形式假设。
4. 设定范围边界和排除项。
5. 识别所需来源、资产或审查需求。
6. 为下一内容阶段产出规划记录。

# 输出

- 主题陈述。
- 受众和平台假设。
- 形式和长度目标。
- 范围边界。
- 开放问题和下一阶段建议。

# 记忆写回

在原始活动日志或项目规划记忆中记录选定主题方向、边界、假设和未解决问题。

# 质量检查清单

- 主题足够具体，能指导脚本。
- 受众和平台明确。
- 边界能防止范围漂移。
- 开放问题与决策分开。

# Agent 兼容性

此技能与 Agent 无关。它依赖结构化规划记录，任何助手或人工协作者都可以应用。
